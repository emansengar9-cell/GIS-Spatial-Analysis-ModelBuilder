# GIS Spatial Analysis using ArcGIS Pro ModelBuilder

> 📍 **Project Type:** GIS Spatial Analysis  
> 🛠️ **Software:** ArcGIS Pro  
> ⚙️ **Tool:** ModelBuilder
> ## 📌 Project Overview

This project demonstrates an automated GIS spatial analysis workflow developed using ArcGIS Pro ModelBuilder.

The workflow applies several geoprocessing operations to select, clip, buffer, and analyze spatial features based on their geographic relationships.
## 🛠️ Tools & Technologies

- ArcGIS Pro
- ModelBuilder
- Spatial Analysis
- Geoprocessing
- Select by Attribute
- Clip
- Buffer
- Select by Location
- Copy Features
- Get Count
- ## 🔄 Workflow

1. Select road features based on attribute criteria.
2. Clip the selected roads to the study area.
3. Create a 50-meter buffer around the clipped roads.
4. Select colleges that intersect the buffer.
5. Copy the selected college features.
6. Calculate the number of selected colleges using Get Count.
